# Assets and provenance

The source in scripts/generate-assets.mjs creates every supplied WAV and SVG cover from mathematical oscillators, deterministic noise, geometric paths and original arrangements. No third-party recordings, samples, melodies, photos, album artwork or Spotify resources were used. Catalog names and artist identities are fictional presentation data.

To the extent copyright applies to the generated audio and cover images, they are made available under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/. No claim is made about the availability or exclusivity of the original Undertone name in any jurisdiction.

The application uses system fonts via CSS and copies no font files. Icons are from lucide-react (ISC license); library dependencies retain their respective licenses in their package distributions. React and Vite use MIT licenses; see the installed package license files. No Spotify branding or protected assets are bundled.
